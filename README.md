# SmartFallMM Dataset

This dataset contains 3-axis accelerometer fall data collected from 23 younger participants simulating five types of falls (front, back, left, right, and rotational).

- Format: CSV
- Sampling rate: 32 ms interval
- Sensor: Smartwatch on left wrist
- Number of files: 237 (each representing a fall sample)

🔗 **Original dataset:** [SmartFallMM on GitHub](https://github.com/txst-cs-smartfall/SmartFallMM-Dataset)

📄 **Used in the paper:**  
_"TransConv-DDPM: Enhanced Diffusion Model for Generating Time-Series Data in Healthcare"_ (COMPSAC 2025)
